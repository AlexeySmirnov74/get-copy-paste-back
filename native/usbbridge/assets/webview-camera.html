Full report
The report contains device names and browser-scoped identifiers. Copy or save it only when you want to share those details.
What this report does and does not identify
deviceId and groupId are browser-scoped values, not USB serial numbers. Web APIs do not expose the Windows PnP path or driver version as dedicated fields. A label may include a model VID:PID. No standard Web API flag proves that a camera is physical or virtual. Unavailable capabilities mean the API did not expose them, not that the device lacks them.
Names, IDs and capabilities depend on camera permission, WebView2 version, driver and website origin. Telegram or another application can expose a different result. This is a local WebView2 measurement, not an emulation of Telegram.
