The workspace fork adds authenticated 48 kHz mono PCM16LE packets to the existing
TCP/MJPEG session. PCM chunks and queues are bounded; underruns and mute supply
zeros, while queue overflow discards oldest complete samples without interrupting
video. Existing JPEG framing, USB audio clock, cancellation and descriptors are
preserved. No physical microphone is opened by the native receiver. See
native\usbbridge\HORIZON-NATIVE.md for framing, limits and build instructions.
The fork also adds explicit MJPEG/YUY2 modes up to 7680x4320 and a fixed
640x480 H264 SEI diagnostic stream. YUY2 bypasses JPEG on the local ingress;
it does not control the codec selected inside Horizon RTAV.
Version 0.2.21 advertises additional 15/10/5 FPS rates within the configured
maximum, negotiates separate UVC PROBE/COMMIT frame intervals, and paces
USB video completions at the committed interval. The H264 probe stays 30 FPS.
Bounded metadata-only HORIZON_UVC control/stream records go to stderr;
HorizonServer copies their recent tail into its ordinary debug log.
The embedded H264 fixture is synthetic black video generated by FFmpeg/libx264,
with a public control marker and no copied user content. Its exact generation
command is retained in tests/Generate-SeiProbeFixture.ps1. No FFmpeg binary or
codec library is distributed or needed at runtime for the fixed probe stream.

This project creates a separate camera configuration, key, serial identity,
loopback TCP listeners and receiver process. No private configuration or key from
the existing USBBridge installation is included. The standalone server reuses
the signed USBIP-WIN2 controller when present. Missing controller setup uses the
bundled, pinned and signature-verified upstream installer after Windows UAC.
Signed driver binaries are unchanged; runtime installation has no download fallback.

The device is an emulated UVC camera with an optional UAC1 capture input using
Windows' inbox camera and audio drivers.
Its virtual USB controller and prototype VID:PID 1209:F002 remain observable.
The prior project's documented target is Windows 11 x64. Compatibility with a
particular Horizon Client/Agent must be verified on the actual deployment.
