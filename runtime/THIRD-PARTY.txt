Horizon third-party components and retained notices

This notice describes the Horizon standalone build inputs. Component licenses
apply to their respective material; they do not specify a project-wide license
for the original Horizon application. Preserve the full license texts, source
pins, notices and Quiet source/relink materials when redistributing this package.
The public source repository also documents these materials in
docs/THIRD-PARTY.md.

EXPLICIT EXPORT FROM THE APPLICATION EXES

Both applications embed Audio-Licenses.zip, quiet-source.zip, quiet-relink.zip,
and the MP4Modem license/integration notice. HorizonServer additionally embeds
ThirdPartyNotices.zip with the native backend notices and retained license tree.
Use --export-third-party with an absolute destination directory to export them.
Export is caller-directed; these materials are not extracted on normal startup.

USBBridge CAMERA BACKEND

USBBridge applications and USB/IP implementation are Rust code, MIT.
  https://github.com/AlexeySmirnov74/USB-to-Network-Bridge
  Horizon fork component version 0.2.21; corresponding source: native/usbbridge/.
  Full license: USBBridge-LICENSE.txt; pinned binary identity: PROVENANCE.txt.
The backend uses the static CRT. Its public ioctl constants and structure
layouts follow the VirtualBox usblib-win.h ABI; no usbipd-win C# implementation
is compiled into the Rust camera backend. Original USBBridge SVG, PNG and ICO
artwork retains its project's MIT license; the native source retains its icon.

The installer provides the virtual host controller and companion filter driver.
The camera backend calls their public control ABI; the driver's WSK transport
handles USB payloads in the Windows kernel. The installer also embeds the
Microsoft Visual C++ Redistributable, retaining Microsoft's original terms.
No third-party kernel binary is modified. Installation is an explicit server
setup operation; normal application startup has no download fallback.
