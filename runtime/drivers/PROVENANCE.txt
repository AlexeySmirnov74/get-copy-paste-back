The original installer includes Microsoft's x64 Visual C++ Redistributable.

driver-installers.json is an unchanged copy of USBBridge's production manifest.
Only its Client package is bundled here. Its Server MSI is not required by the
local emulated camera and is not bundled with HorizonServer.

DriverInstaller.cs adapts USBBridge's strict offline C# Authenticode verifier.
It requires the complete pinned installer digest and the expected publisher.
Certificate/revocation URL
retrieval is disabled. After the digest matches it can cache the exact public
GlobalSign GCC R45 EV CodeSigning CA 2020 intermediate in CurrentUser/CA only;
its SHA-256 is CD0E144DD10BAC221FE2FB901058D16450A0578B3C47C770908F2E9ADA28EF12.
Windows must already trust the upstream root. No root/trusted-publisher
certificates are installed, and driver signatures/Secure Boot are not bypassed.

Automatic setup first probes usbbridge-camera.exe driver-ready. If ready=true,
no driver installation or certificate verification/store operation is performed.
When missing, the already-elevated setup helper verifies and silently launches
the original installer with the same components as USBBridge production setup:
/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /RESTARTEXITCODE=3010 /SP- /NOICONS
/TYPE=custom /COMPONENTS=main,client /TASKS=vcredist
/DIR="[ProgramFiles]\USBip" /LOG="[runtime root]\data\driver-install.log"
Exit 3010 requests a manual Windows restart; the application never restarts it.
An installer timeout is reported without terminating its driver-store update.
