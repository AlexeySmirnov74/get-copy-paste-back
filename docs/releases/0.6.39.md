# Get Copy-Paste Back 0.6.39

- The product is now **Get Copy-Paste Back**, with repository [AlexeySmirnov74/get-copy-paste-back](https://github.com/AlexeySmirnov74/get-copy-paste-back). Run `Server.exe` on the local PC and `Client.exe` inside the remote desktop. Download matching versions or `Get-Copy-Paste-Back-0.6.39.zip`.
- Includes the fixes prepared locally in 0.6.38: the server receives return audio from all active local playback outputs by default, using separate decoders and shared duplicate suppression. Explicit device and Windows-default choices survive restart; older settings without an audio preference adopt the all-output default.
- The disabled camera-name control keeps its text unselected after native handle recreation, focus and language changes. Camera-name editing remains available when no camera exists.
- Compatibility paths remain `HorizonServer/` beside the server and `HorizonClient/Settings` under the client's writable settings location, normally `%LOCALAPPDATA%`. Existing namespaces, resource identifiers and helper/component names are retained so settings and offline resources continue to work.
- Native component versions, source pins, license terms, wire formats and clipboard bounds are retained. Listening on several local outputs discovers the return route; it adds no independent Horizon channels or promised bandwidth.

Validation covers synthetic audio, isolated settings/XML and hidden Windows Forms fixtures. Routine build checks do not open real devices, install drivers or measure Horizon throughput.

## Русский

- Новое название продукта — **Get Copy-Paste Back**, репозиторий — [AlexeySmirnov74/get-copy-paste-back](https://github.com/AlexeySmirnov74/get-copy-paste-back). `Server.exe` запускается на локальном ПК, `Client.exe` — внутри удалённого рабочего стола. Используйте одинаковые версии или архив `Get-Copy-Paste-Back-0.6.39.zip`.
- Включены исправления локальной версии 0.6.38: сервер по умолчанию принимает обратный звук со всех активных локальных аудиовыходов, отдельно декодирует потоки и подавляет повторы. Ручной выбор устройства или устройства Windows по умолчанию сохраняется после перезапуска; старые настройки без аудиопредпочтения используют новый режим по умолчанию.
- Недоступное поле названия камеры остаётся без выделения после пересоздания элемента Windows, смены фокуса и языка. Когда камеры нет, название можно редактировать.
- Для совместимости сохранены папка `HorizonServer/` рядом с сервером и `HorizonClient/Settings` в доступном клиенту расположении настроек, обычно под `%LOCALAPPDATA%`. Прежние пространства имён, идентификаторы ресурсов и имена вспомогательных файлов/компонентов сохраняют работу настроек и автономных ресурсов.
- Сохранены версии нативных компонентов, закреплённые исходники, лицензии, форматы протоколов и ограничения буфера. Приём с нескольких локальных выходов помогает найти обратный маршрут, но не создаёт независимых каналов Horizon и не обещает роста скорости.

Проверки используют синтетический звук, изолированные XML/настройки и скрытые формы Windows Forms. Обычная проверка сборки не открывает реальные устройства, не устанавливает драйверы и не измеряет скорость Horizon.
