# Horizon-Enable-CopyPaste 0.6.37

## English

- Added **Settings → Four-color modes** on the server. It saves the preference
  and adds four 720p/1080p choices with 4/8-pixel cells to the transfer dropdown
  and speed test. Turn it off to keep the original five modes. Fresh installs
  default to off; existing experiment color selections migrate safely.
- Color frames use per-frame calibration and CRC-protected packets. Turning
  color off during a pending copy restarts it with a new transfer identity.
  Camera formats remain the existing YUY2 choices; no driver change is needed.
- Fixed audio-output preference loss after transient server enumeration and
  failed/superseded client audio probes. Available explicit choices are restored
  at restart; stable identities prevent silently choosing a different endpoint
  when Windows reorders devices. Missing choices are retained for recovery.
- An entirely failed speed test now advises checking the selected audio output
  on both the server and client and using the client's **Test audio** command.
- Verified native EXE icons and tray resources for both programs, and the
  server's shared window/tray icon instance. Updated both READMEs with live
  release/build badges, ready-built download links and color-mode instructions.

Both matching EXEs are included. Run the server locally and the client inside
remote Windows. Camera/audio redirection must be enabled by the environment.
Measured color throughput is connection-specific; calculated frame capacities
are not a guarantee of 100 Mbit/s or uncompressed Horizon transport.

Validation: full managed build and configured synthetic/fixture suite, including
color calibration/integrity, settings migration/toggle, both audio preferences,
benchmark feedback/guidance, hidden bilingual UI and native/managed icon checks.
No installer, driver or real clipboard/audio/camera operation was run by tests.

## Русский

- В настройках сервера добавлен параметр **«Цветные режимы (4 цвета)»**. Он
  сохраняется и добавляет четыре режима 720p/1080p с ячейками 4/8 пикселей в
  выбор передачи и проверку скорости. Без галочки остаются прежние пять режимов.
  По умолчанию галочка выключена; выбор из экспериментальной версии переносится.
- Цветные кадры калибруются по эталонам каждого кадра и проверяются по CRC.
  Отключение цвета при передаче перезапускает её с новым идентификатором.
  Форматы камеры остаются YUY2; менять драйвер не требуется.
- Исправлена потеря выбора аудиоустройства при временно пустом списке сервера
  и при неудачном/заменённом звуковом тесте клиента. Доступный выбор восстанавливается
  после перезапуска. Изменение порядка устройств не должно менять выбранный выход;
  временно отсутствующий выход сохраняется для восстановления.
- Если проверка скорости не прошла ни в одном режиме, программа предлагает
  проверить аудиовыход на сервере и клиенте и нажать **«Проверить звук»** на клиенте.
- Проверено совпадение значков EXE и трея обеих программ. В README на обоих языках
  добавлены актуальные значки релиза/сборки, ссылки на готовые EXE и описание цвета.

Сервер запускается локально, клиент — внутри удалённой Windows. Нужны разрешённые
проброс камеры и звук Horizon. Скорость зависит от подключения; ёмкость кадра
не означает гарантированные 100 Мбит/с или отсутствие сжатия внутри Horizon.
