# 0.6.38 — local build / локальная сборка

This version has not been published to GitHub at the owner's request.

- Server return-audio reception defaults to all active local playback outputs. Independent decoders preserve duplicate suppression; explicit device and Windows-default choices survive restart.
- Existing endpoint preferences are retained. Older settings without an audio preference adopt the all-output default.
- A disabled camera-name control keeps its text unselected after native handle recreation, focus and language changes. Editing remains available when there is no camera.
- Validation uses offline synthetic audio, isolated XML and hidden WinForms fixtures; no real device or driver operation is part of the build.

Эта версия подготовлена локально и по просьбе владельца не опубликована на GitHub.

- Сервер по умолчанию принимает обратный звук со всех активных аудиовыходов локального ПК. Потоки декодируются отдельно, повторы не дублируют буфер. Ручной выбор устройства или устройства Windows по умолчанию сохраняется после перезапуска.
- Существующие настройки конкретного устройства сохранены. Старые настройки без выбранного аудиовыхода используют новый режим по умолчанию.
- Недоступное поле названия камеры остаётся без выделения после пересоздания элемента Windows, смены фокуса и языка. Когда камеры нет, редактирование работает как раньше.
- Проверки сборки используют синтетический звук, изолированные XML и скрытые формы; настоящие устройства и драйверы не запускаются.
