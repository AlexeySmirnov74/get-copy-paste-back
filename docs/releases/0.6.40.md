# Get Copy-Paste Back 0.6.40

- Automatic client camera discovery tries the saved exact device ID first, including a previously selected custom camera name. Other candidates must exactly match one of the server's 100 camera names; both roles share the same catalog.
- Unsaved cameras outside that catalog are skipped automatically. A matching name is only a candidate filter: the client still requires valid application control packets. A physical camera whose name matches the catalog can therefore activate briefly.
- Discovery uses a finite pass through up to five DirectShow/Media Foundation compatibility modes instead of cycling indefinitely. Exhausted candidates become eligible again after automatic selection is explicitly turned off and on, or the client restarts. A newly appearing device ID remains eligible for discovery.
- For a server camera with a custom name outside the catalog, select it manually in the client first. Manual selection takes precedence, disables automatic selection and saves the choice.
- Camera backend identities, runtime/settings locations, native component versions and wire formats are retained.

## Русский

- Автопоиск камеры в клиенте сначала проверяет сохранённый точный ID устройства, включая ранее выбранную камеру с произвольным именем. Остальные кандидаты должны точно совпадать с одним из 100 имён серверного каталога; обе стороны используют один каталог.
- Несохранённые камеры вне каталога автоматически пропускаются. Совпадение имени только отбирает кандидата: клиент по-прежнему требует корректные служебные пакеты приложения. Поэтому физическая камера с именем из каталога может ненадолго включиться.
- Вместо бесконечного перебора выполняется конечный проход не более чем по пяти режимам совместимости DirectShow/Media Foundation. Исчерпавшие проход камеры снова доступны после явного выключения и включения автовыбора либо перезапуска клиента. Устройство с новым ID по-прежнему может быть обнаружено позднее.
- Если серверная камера имеет произвольное имя вне каталога, сначала выберите её в клиенте вручную. Ручной выбор имеет приоритет, отключает автоматический и сохраняется.
- Сохранены идентификаторы backend камеры, расположения runtime/настроек, версии нативных компонентов и форматы протоколов.
