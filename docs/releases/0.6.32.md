## English

First public release of **Horizon-Enable-CopyPaste**.

- Separate portable Windows x64 applications: `HorizonServer.exe` for the local PC and `HorizonClient.exe` for the remote Windows desktop.
- Clipboard, files and folders travel forward through the redirected camera and back through Horizon audio, with compression, integrity checks and delivery confirmations.
- Fixed unwanted camera-name highlighting in the server settings; custom names remain editable.
- English is the default language; Russian is available in both applications.
- English/Russian guides, visual explanations, honest speed estimates and contributor/agent instructions are included in the repository.
- Full synthetic test suite and packaged native/driver resource checks pass. Physical Horizon throughput and compatibility still depend on the user's environment.

Download both EXEs separately or the ZIP containing both and a quick-start guide. Verify the downloads with `SHA256SUMS.txt`. Driver installation is offline from embedded inputs and may require administrator permission.

Possible future work: virtual audio drivers and several independently redirected audio channels. This is a proposal, not an implemented feature or a promised speed increase.

## Русский

Первый публичный релиз **Horizon-Enable-CopyPaste**.

- Два отдельных EXE для Windows x64: сервер на локальном ПК, клиент внутри удалённой Windows.
- Буфер обмена, файлы и папки передаются туда через камеру, обратно через звук Horizon. Есть сжатие, проверка целостности и подтверждение доставки.
- Исправлено лишнее выделение названия камеры в настройках сервера; своё название по-прежнему можно вводить.
- Английский включён по умолчанию, русский доступен в обеих программах.
- Добавлены инструкции на двух языках, понятные схемы и оценки скорости с указанием ограничений замеров.
- Полный набор синтетических проверок и проверки встроенных драйверов/модемов проходит. Совместимость и реальная скорость через Horizon зависят от конкретного подключения.

Скачайте два EXE отдельно или ZIP с обеими программами и краткой инструкцией. Для проверки файлов есть `SHA256SUMS.txt`. Драйвер устанавливается без скачивания из интернета; Windows может запросить права администратора.

Возможное развитие: виртуальные аудиодрайверы и несколько независимых обратных аудиоканалов. Это план, а не готовая функция и не обещание увеличения скорости.
