## English

- New shared green clipboard-and-arrows icon for both applications and tray menus, with native sizes from 16 to 256 pixels.
- Client audio libraries now extract into the selected settings directory's `audio-native` child: normally `%LOCALAPPDATA%\HorizonClient\Settings\audio-native`, with the existing Roaming/EXE-directory fallback.
- Client-received files and folders stay in bounded memory and are offered through the Windows Shell virtual-file clipboard. The client no longer creates a `Received` directory or intermediate received-file copies. Keep it running until pasting into File Explorer finishes; destinations accepting only existing filesystem paths may not support virtual files.
- Text/image clipboard behavior, transfer integrity/size limits and the local server's reverse-file storage remain unchanged. Existing user files and legacy DLL folders are not deleted automatically.
- English/Russian guides and in-app help describe the new storage and paste behavior.
- Log-storage fixtures explicitly wait for their own background writer to close before reading or deleting its files. A bounded production shutdown is no longer mistaken for guaranteed immediate closure by the tests.

Download the matching server and client EXEs, or the ZIP containing both. Verify downloads using `SHA256SUMS.txt`. Synthetic checks cover memory-file descriptors, stream negotiation/ownership, receiver preparation without disk writes, audio storage and the packaged DLLs. Real Horizon and destination-application compatibility still requires checking in your environment.

## Русский

- Новый общий зелёный значок буфера обмена с двумя стрелками для обеих программ и трея, с размерами от 16 до 256 пикселей.
- DLL аудиомодемов клиента извлекаются в подпапку `audio-native` выбранной папки настроек: обычно `%LOCALAPPDATA%\HorizonClient\Settings\audio-native`, с прежним резервом в Roaming или папке EXE.
- Принятые клиентом файлы и папки остаются в ограниченной памяти и передаются Проводнику как виртуальные файлы буфера Windows. Клиент больше не создаёт `Received` и промежуточные копии принятых файлов. Не закрывайте его до завершения вставки в Проводник; приложения, которым нужны пути к уже существующим файлам, могут не поддерживать такую вставку.
- Передача текста/изображений, проверки целостности, ограничения размера и хранение обратных файлов на локальном сервере сохранены. Старые пользовательские файлы и каталоги DLL автоматически не удаляются.
- Обновлены инструкции на двух языках и встроенная справка.
- Тесты хранения журналов дожидаются закрытия собственного фонового потока перед чтением и удалением файлов. Короткий рабочий таймаут завершения больше не принимается тестом за гарантию немедленного закрытия.

Скачайте оба EXE одной версии или ZIP с обеими программами. Контрольные суммы находятся в `SHA256SUMS.txt`. Синтетические проверки охватывают описания виртуальных файлов, запросы и освобождение потоков, подготовку приёма без записи файлов, пути хранения аудиобиблиотек и встроенные DLL. Совместимость с вашим Horizon и приложениями для вставки нужно проверить в рабочем окружении.
